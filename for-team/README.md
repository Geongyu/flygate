# 팀 레포로 올릴 후보

**아직 아무것도 올리지 않았다.** 팀 레포(`korea-agentic-hackathon-2026`)에는
건규가 직접 지시할 때까지 커밋하지 않는다.

## 들어 있는 것

- `SKILL.md` — 근거 검증 스킬 초안 (3단 게이트 + 반려 규칙 15개).
  NVIDIA 스킬 규격이 요구하는 동반 파일 중 `skill-card.md`, `evals/evals.json`,
  `BENCHMARK.md` 는 아직 안 썼다. `skill.oms.sig` 는 NVIDIA 서명이라 우리가 못 만든다.

## 올릴 때 지켜야 할 팀 규칙

`docs/CONVENTIONS.md` 에서:

- `.env` 는 커밋하지 않는다.
- 커밋 저작자는 각자 본인 GitHub 신원이다. AI 도구를 공동저자나 생성자로 적지 않는다.
  트레일러와 꼬리말을 넣지 않고 커밋 메시지 본문에도 언급하지 않는다.

가경님 지시:

- 검토 의견은 기존 문서를 고치지 말고 `review-이름.md` 로 새로 만든다.
- `configs` 폴더와 `register.py` 는 가경님이 고친다. 도구는 새 파일까지만 만들고
  배선은 넘긴다.
